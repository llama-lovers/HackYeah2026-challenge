## Phase Goal

**As a** blind user on inpost.pl, **I want to** press a shortcut, say a Polish command and have the agent click or fill what I described, **so that** I hear through my own screen reader what the agent did and what actually changed, while my sensitive data stays masked and the API key never leaves the proxy.

This plan's slice: the key-holding Python proxy. After it, any extension-origin client can turn audio into a transcript and a page snapshot plus utterance into a validated action proposal, and a diff into a one-sentence Polish effect summary, without the key ever leaving the server.

Purpose: PROXY-01..03 and the proxy half of VOICE-03; the teammate builds the Whisper module against the frozen transcribe() seam.
Output: server/ package (uv-managed), pytest suite, fake upstream, .env.example.
</objective>
