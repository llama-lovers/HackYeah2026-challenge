## Phase Goal

**As a** blind user on inpost.pl, **I want to** press a shortcut, say a Polish command and have the agent click or fill what I described, **so that** I hear through my own screen reader what the agent did and what actually changed, while my sensitive data stays masked and the API key never leaves the proxy.

This plan's slice: everything the extension needs to *see* a real page safely and *decide* safely, proven in real Chromium on offline fixtures before any runtime wiring: the masked snapshot (exactly the text the model will receive), the fail-closed proposal validator, the push-to-talk turn reducer, every Polish sentence, the fixed extension identity, and the CDP harness the later E2E smoke builds on.
