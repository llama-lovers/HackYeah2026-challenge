## Phase Goal

**As a** blind user on inpost.pl, **I want to** press a shortcut, say a Polish command and have the agent click or fill what I described, **so that** I hear through my own screen reader what the agent did and what actually changed, while my sensitive data stays masked and the API key never leaves the proxy.

This plan's slice: the agent now *confirms effects, not intentions* (differentiator 2). After a fill or click the user hears what actually changed on the page, or that nothing changed, also across a full page navigation. The plan closes the phase with automated proof of success criteria 3-5 and the end-of-phase screen-reader and network checks.

<objective>
Add the settle watcher, the deterministic diff, the effect announcement (template for empty diffs, second model call otherwise, fixed fallback on failure), and the D-05 navigation handoff; then prove refusals, turn-taking edges, masking and body-free logging end to end in Chromium, and gather the human acceptance checks.

Purpose: ACT-02 and ACT-07 complete, OUT-01 consecutive-message behavior, success criteria 2-5.
Output: diff.ts, settle.ts, effect/navigation wiring, E2E scenarios effect, navigation, turns, refusals, privacy.
</objective>

extension/src/shared/diff.ts (pure, Claude's discretion per CONTEXT): diffSnapshots(before: Snapshot, after: Snapshot): PageDiff and isEmptyDiff(d: PageDiff): boolean. Interactive nodes are matched by the key role|name|ordinal (ordinal = index among nodes with the same role and name in document order; ids are not stable across snapshots). For matched interactive nodes emit changed entries for disabled flips ("disabled"/"enabled"), value differences ("value", to = after.value), checked, expanded and invalid flips. Unmatched interactive nodes go to added/removed as "{role} {name}". Heading and text nodes are compared as multisets of collapsed strings (only the surplus count is added/removed); alert nodes are compared the same way but new ones go to alerts. path/title transitions when they differ. Caps: added 8, removed 5, changed 8, alerts 3, every string truncated to 160 code points (the proxy accepts at most 200). Both inputs are already masked snapshots, so the diff never re-reads the DOM and cannot bypass masking. Tests in diff.test.ts per the behavior list.
