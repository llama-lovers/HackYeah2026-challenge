## Phase Goal

**As a** blind or low-vision user, **I want to** find my way around an ordinary page by voice, **so that** I can understand what is present and what I can safely do without being left in silence.

<objective>
Deliver the read-only exploration path for PAGE-02 and PAGE-03: one grounded page summary, a bounded list of actually available actions, and user-invoked access to ordinary top-level HTTP(S) pages.

Purpose: Prove the phase's hardest boundary first: untrusted page text and model output may describe a page but can never acquire mutation authority.
Output: Strict exploration proxy contract, temporary active-tab preparation, locally validated candidate projection, and a deterministic browser scenario.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page → content script | Untrusted DOM text and controls become masked bounded evidence and locally eligible candidates. |
| content script → service worker | Runtime messages must retain extension sender, top-frame, tab, document and epoch ownership. |
| extension → proxy | Masked exploration JSON crosses the network boundary; the key remains server-side. |
| proxy → model provider | Untrusted page evidence is fenced; strict output is still validated locally before use. |

## STRIDE Threat Register (OWASP ASVS 5.0, Level 1; high severity blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering / Elevation | /api/explore prompt and result | high | mitigate | Dedicated read-only schema, fenced page data, no execution branch, runtime response decoder and browser assertion of zero action messages. |
| T-03-02 | Spoofing / Tampering | available-action ids | high | mitigate | Require unique subset membership in a locally eligible set and recheck document, epoch and live policy after the model response. |
| T-03-03 | Information disclosure | activeTab + scripting | high | mitigate | Grant only on explicit command, restrict to top-level HTTP(S), inject frame 0 only, retain proxy-only persistent host permission and never summarize automatically. |
| T-03-04 | Spoofing | runtime content messages | high | mitigate | Validate extension sender, frame 0, original tab, document id, turn id and message payload before accepting evidence. |
| T-03-05 | Denial of service | model output | medium | mitigate | Bound request nodes/text, sentence and id arrays; reject null/extra/excess output; keep existing timeouts and one completion. |
| T-03-06 | Information disclosure | exploration storage/logging | medium | mitigate | Store no transcript/snapshot/history for exploration and retain body-free proxy logging and egress masking tests. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | Add no package; restore only existing lockfiles. Any executor-proposed new package requires the legitimacy gate before installation. |
</threat_model>
