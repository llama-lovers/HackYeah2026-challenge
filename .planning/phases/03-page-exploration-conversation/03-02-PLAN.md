## Phase Goal

**As a** blind or low-vision user, **I want to** repeat, tune and move through page information by voice, **so that** I control the conversation without extra model calls or loss of orientation.

<objective>
Add deterministic local conversation commands for repeat, persistent three-level verbosity and measured document scrolling.

Purpose: Keep simple control commands fast, private and reliable across MV3 worker restarts while preserving the read-only exploration and Phase 1 safety boundaries.
Output: Pure command grammar, session-scoped replay, durable non-sensitive preference, scroll protocol/handler and browser coverage.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page output → session replay | Page-derived speech may be replayed only in its original tab/document and never durably. |
| voice transcript → local router | Complete allowlisted commands must not steal arbitrary dictation or bypass the action pipeline. |
| local preference → proxy prompt | One validated non-sensitive enum crosses storage and request boundaries. |
| worker → content scroll | A stale or forged message must not move a changed page or steal focus. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-07 | Information disclosure | replay storage | high | mitigate | One bounded session-only response keyed by tab/document, written after delivery ACK, invalidated on navigation/closure and absent after restart. |
| T-03-08 | Tampering | verbosity storage | medium | mitigate | Decode an exact enum, default malformed data, acknowledge only successful writes and persist no page-derived content. |
| T-03-09 | Spoofing / Tampering | SCROLL runtime message | high | mitigate | Validate sender/frame, tab, turn and docId before immediate scroll; measure result and preserve focus. |
| T-03-10 | Elevation | local command grammar | high | mitigate | Match complete normalized phrases before routing; unknown/embedded phrases retain the validated action path. |
| T-03-11 | Denial of service | repeated output | medium | mitigate | Bound replay length and use existing FIFO announcer; replay does not self-save or create an output loop. |
